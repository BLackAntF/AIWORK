### fix(test): 修复全链路测试确认的统计与数据显示缺陷
**Commit**: 03427a1
**分支**: master
**变更文件数**: 7
**代码行数**: +541 / -126

**背景**：
- 全链路测试（Web 用户端 / Web 管理端 / H5 移动端）复验中发现 4 处数据展示缺陷，另有 2 处页面解析问题
- 约束：仅修复数据口径与字段绑定，不改视觉样式、不改接口成功码约定（`code=0`）

**修改内容：**

**① 管理端检测记录页统计恒为 0（`frontend/src/views/admin/Detections.vue`）**
- 根因：后端 `/api/admin/detections/stats` 返回 `{total, today, avg_processing_time}`，前端读取 `stats.total_count` / `stats.today_count`，字段名不匹配导致「总检测数」恒为 0
- 修复：模板绑定改为 `stats.total` / `stats.today`，异常兜底对象键名同步为 `{total: 0, today: 0, avg_processing_time: 0}`

**② H5 首页累计检测统计口径错误（`backend/routes/history.py` + `mobile/src/api/history.js` + `mobile/src/pages/index/index.vue`）**
- 根因：首页原先仅按「最近 5 条历史记录」在前端本地统计，口径与全量数据不符
- 后端新增 `GET /api/history/stats`（`@login_required`）：按当前用户全量记录统计，依据 `class_names` 与 `HEALTHY_CLASS_NAMES = {'健康','健康叶片','健康叶子','正常叶片','Healthy'}` 判定，返回 `{total, disease_count, healthy_count}`
- 移动端新增 `getHistoryStats()` API，首页 `stats` 状态改为读接口值，`totalCount / diseaseCount / healthyCount` 均由接口驱动；`loadRecords()` 末尾追加 `loadStats()`（统计失败不影响列表展示）

**③ H5 首页病害名/状态依赖不存在字段（`mobile/src/pages/index/index.vue`）**
- 根因：`DetectionHistory.to_dict(include_detail=False)` 不返回 `detections`，原 `isHealthyRecord` / `getStatusLabel` / `getDiseaseName` 依赖该字段，导致列表状态与病害名异常
- 修复：新增 `classList(record)` 统一解析 `record.class_names`（逗号分隔），三个展示函数全部改为基于 `class_names` 判定，无结果时回退 `original_filename`

**④ AI 会话标题乱码（`backend/routes/knowledge.py`）**
- 根因：历史测试脏数据中存在编码异常标题（如 `??????????`、`??????????????(?????`），在会话列表中展示为乱码
- 修复：新增 `_is_garbled_title(text)`（不含任何中文且问号计数 ≥ 3 判定为乱码，正常英文标题单个问号不误判）与测试会话黑名单 `_TEST_SESSION_IDS`；`get_session_list` 循环内跳过命中项（非破坏性过滤，不删数据）

**⑤ 文档**
- 新增 `docs/全链路测试报告-0928.md`：总体结论表、6 项缺陷修复清单、构建验证表、遗留与阻断项、接口契约补充表
