## 三、技术要点与排障记录

| 事项 | 说明 |
|------|------|
| 检测上下文传递链路 | Detect/HistoryDetail → setDetectionContext 或 URL query → Knowledge.vue onMounted 读取 → sendMessage 携带 detection_context + detected_class_id → 后端注入病害档案到 LLM prompt |
| 预设问题时序竞争 | loadSessions 内 switchSession 为异步（await getChatHistory），完成后覆盖 messages；修复：预设问题场景跳过自动切换会话（`&& !presetQuestion.value`） |
| 报告导出 | axios blob → 读 HTML 文本 → 拼接后端 base URL 替换 `/static/` 相对资源路径 → Blob URL → window.open；规避 document.write 被 TRAE overlay 覆盖 |
| PowerShell curl 陷阱 | `curl` 是 Invoke-WebRequest 别名，改用 `(Invoke-WebRequest -UseBasicParsing)` 取 StatusCode |
| LLM 配置生效 | 配置在 `backend/.env`（gitignore），后端重启后生效；API Key 仅存 .env 不落代码 |
