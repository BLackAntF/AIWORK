## 1. 实验一：Slim-Neck 轻量化改进（已完成 · 负结果）

### 1.1 改动内容
将 yolo26n head 中 6 个 `C3k2` 模块替换为 `GSConv` + `VoVGSCSP`（Slim-Neck 轻量化 neck），降低参数量与计算量。

### 1.2 源码改动
- 新增模块文件 `ultralytics/nn/modules/Slim_Neck.py`（含 `GSConv` / `GSBottleneck` / `GSBottleneckC` / `VoVGSCSP`）
- `tasks.py` 改动：
  - 新增 import：`from ultralytics.nn.modules.Slim_Neck import GSConv, GSBottleneck, GSBottleneckC, VoVGSCSP`
  - `base_modules` frozenset 加入 `GSConv`、`VoVGSCSP`
  - `repeat_modules` frozenset 加入 `VoVGSCSP`

**证据文件**：
- 源码改动 diff：[slimneck_experiment/patch/records/tasks.py.diff](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/patch/records/tasks.py.diff)
- 新增模块源码：[slimneck_experiment/source_patch_snapshot/Slim_Neck.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/source_patch_snapshot/Slim_Neck.py)
- 改动前后 tasks.py 快照：[source_patch_snapshot/](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/source_patch_snapshot)
- 补丁脚本：[patch_slimneck.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/patch/patch_slimneck.py)（幂等，含备份与 diff 生成）

### 1.3 结构对比（实测）

## 2. 实验二：CBAM 注意力改进（已完成 · 负结果）

### 2.1 改动内容
在 yolo26n backbone 的 P3 / P4 / P5 三级输出后各插入一个 CBAM 模块（通道注意力 + 空间注意力），强化病害纹理特征的通道与空间选择。

### 2.2 源码改动
CBAM 类已存在于官方 `ultralytics/nn/modules/conv.py`（L592-622），但未被 `tasks.py` import，因此需在 `tasks.py` 的 import 列表中加入一行：

```python
from ultralytics.nn.modules import (
+   CBAM,
    AIFI,
    C1,
    ...
)
```

CBAM 走 parse_model 的非 base_modules 兜底分支（`c2 = ch[f]`），通道数不变，故 yaml 中通道数需按 n 尺寸手写：P3=128、P4=128、P5=256。

**证据文件**：
- 模型 yaml：[yolo26n-CBAM.yaml](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/yolo26n-CBAM.yaml)
- 注册脚本：[register_cbam.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/register_cbam.py)（幂等，含备份 tasks.py.bak_cbam，`revert` 可还原）
- 改动后任务模型结构：275 层（基线 260 层）

### 2.3 结构对比（实测，本机与服务器双重验证一致）

| 模型 | 参数量 | GFLOPs | 差值 |
|---|---|---|---|
| 基线 yolo26n | 2,572,280 | 6.24 | — |
| CBAM yolo26n | 2,671,390 | 6.24 | +3.85% / +0.00% |

**证据文件**：[verify_structure.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/verify_structure.py) 输出。

### 2.4 训练结果
训练至 epoch 80 中断（用户决定停止，转蒸馏路线），best 出现在 epoch 73。

| 指标 | 基线 best@182 | CBAM best@73 | 差值 |
|---|---|---|---|
| mAP50 | 0.95778 | 0.95783 | +0.005pp（持平） |
| mAP50-95 | 0.93667 | **0.92134** | **−1.53pp** |
| Precision | 0.97627 | 0.98023 | +0.40pp |
| Recall | 0.89878 | 0.89604 | −0.27pp |

**证据文件**：
- 训练指标：[run_output/results.csv](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/run_output/results.csv)（80 行）
- 训练超参：[run_output/args.yaml](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/run_output/args.yaml)
- 训练脚本：[train_structure.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/structure_experiment/train_structure.py)
- 权重：`run_output/weights/best.pt`（16MB，因中断未跑 strip_optimizer）

### 2.5 结论
CBAM 的 mAP50 与基线持平，但 mAP50-95 下降 1.53pp。与 Slim-Neck 趋势一致：在该高饱和度整叶标注数据集上，注意力结构改动未能提升检测精度。作为负结果留档，可写入论文消融实验表。

## 3. 实验三：Slim-Neck + 知识蒸馏（进行中）

> 目标：保留 Slim-Neck 轻量化结构作为论文核心结构贡献，同时用蒸馏 + 训练策略把精度补回并超过基线。

### 3.1 改进手段（三个贡献点）

| 贡献点 | 手段 | 作用 |
|---|---|---|
| ① 结构改进 | Slim-Neck（head C3k2→GSConv/VoVGSCSP） | 轻量化，−4.49% 参数 |
| ② 精度恢复 | 知识蒸馏（yolo26s 教师 → Slim-Neck 学生） | 弥补轻量化损失的表达能力 |
| ③ 训练策略 | cls_pw=0.5 + close_mosaic=20 + cls=0.8 | 针对类别不平衡（3.5x）与分类收敛 |

### 3.2 教师模型（yolo26s）

| 项 | 值 |
|---|---|
| 模型 | yolo26s（从 COCO 预训练权重微调） |
| 参数量 | 9,955,604 (9.956M) |
| GFLOPs | 22.8 |
| 训练超参 | epochs=200, patience=999, batch=32, imgsz=640, seed=0 |

**证据文件**：
- 教师训练脚本：[train_teacher_s.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/patch/train_teacher_s.py)

**证据文件**：
- 学生训练脚本：[train_student_distill.py](file:///d:/Develop/CODE/AIWORK/Projects/yolo-detection-system/training/slimneck_experiment/patch/train_student_distill.py)

### 3.4 判定标准
学生模型 best 轮次的 **mAP50-95 > 0.93667（基线）** 即视为改进成功。主判据用 mAP50-95（mAP50 已饱和接近天花板），且逐类指标不出现明显退化（尤其花叶病毒病）。
