> 更新日期：2026-10-12
> 前置状态：`npm run build:app` 已构建通过（产物 `mobile/dist/build/app/`），manifest.json 配置齐全
> HBuilderX 位置：`D:\Develop\codeApp\HBuilderX`（需先启动 HBuilderX 主程序）

## 一、前置条件

| 条件 | 说明 |
|------|------|
| 手机与电脑同一 WiFi | App 内置 API 地址为 `http://192.168.31.27:5000/api`（构建时自动注入的电脑局域网 IP） |
| 电脑防火墙放行 5000 端口 | 否则手机 App 无法访问后端（Windows 防火墙 → 入站规则 → 新建放行 TCP 5000） |
| 后端已启动 | 电脑上运行 `python app.py`（backend 目录） |
| DCloud 账号 | HBuilderX 登录（云打包必须）；无账号在 HBuilderX 内免费注册 |

## 二、方式一：云打包生成 APK（推荐）

1. 启动 HBuilderX → 菜单「文件 → 打开目录」→ 选择 `Projects\yolo-detection-system\mobile`
   （HBuilderX 会识别为 uni-app CLI 项目；首次打开提示安装编译插件按提示装即可）
2. 菜单「发行 → 原生 App-云打包」
3. 打包对话框配置：
   - Android 包名：如 `com.yourname.tomatodisease`（自定义，一经发布不要改）
   - 打包类型：使用公共测试证书（测试阶段够用；正式上架需自建证书）
   - 渠道包：无需勾选
4. 确认后进入云端打包队列，完成后 HBuilderX 控制台给出 APK 下载链接
5. APK 传到手机安装（需允许未知来源安装）

## 三、方式二：真机调试基座（先跑通再打包，推荐先用这个）

1. 手机开启「USB 调试」，数据线连接电脑
2. HBuilderX 打开 mobile 项目 → 菜单「运行 → 运行到手机或模拟器 → 选择你的设备」
3. HBuilderX 自动安装标准基座（HBuilder）到手机，改动代码热更新，无需重复打包
4. 跑通登录/检测/历史全流程后，再走方式二生成正式 APK

## 四、注意事项

1. **API 地址是构建时写死的**：电脑换网络（IP 变了）需重新执行 `npm run build:app` 再打包；HBuilderX 发行 CLI 项目会自动执行 `build:app-plus` 脚本（已补入 package.json，与 `build:app` 等价，同样自动注入局域网 IP）
2. **HTTP 明文已放行**：manifest.json `usesCleartextTraffic: true`，允许 App 访问 `http://` 后端（开发期必需；上生产建议后端上 HTTPS 后改回）
3. **应用图标**：云打包对话框里可在线生成图标（选一张 1024x1024 的番茄/叶片主题图即可）
4. **首次安装启动慢**：正常，uni-app 运行时初始化
5. **微信小程序**：`npm run build:mp-weixin` 产物在 `dist/build/mp-weixin`，微信开发者工具导入即可（appid 已配置 `wxb6f35358854439ff`）；注意小程序真机调试同样需要后端域名 HTTPS（开发阶段可在开发者工具勾选「不校验合法域名」）
