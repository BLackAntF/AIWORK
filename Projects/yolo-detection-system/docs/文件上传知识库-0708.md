# 文件上传添加知识库 - 0708

## 任务类型
前后端联合开发

## 需求描述

允许用户/管理员上传文件（PDF、DOCX、TXT、MD），自动解析文件内容并添加到知识库。

## 功能需求

### 1. 后端 - 文件解析服务

**新增服务**：`file_parser.py`

**支持的文件格式**：
- `.txt` - 纯文本文件
- `.md` - Markdown 文件
- `.docx` - Word 文档
- `.pdf` - PDF 文件

**解析逻辑**：
- 提取文件标题（文件名或文档标题）
- 提取文件内容（全文）
- 自动生成摘要（前200字）

**依赖安装**：
```bash
pip install python-docx PyPDF2
```

### 2. 后端 - 上传接口

**管理员上传**（直接生效）：
```
POST /api/admin/knowledge/upload
Content-Type: multipart/form-data
Body: { file, category?, source?, tag_ids? }
Response:
{
  "code": 200,
  "data": {
    "id": 1,
    "title": "...",
    "content": "...",
    "summary": "..."
  },
  "message": "知识已创建"
}
```

**用户上传**（需审核）：
```
POST /api/knowledge/upload
Content-Type: multipart/form-data
Body: { file, category?, source?, tag_ids? }
Response:
{
  "code": 200,
  "data": {
    "id": 1,
    "title": "...",
    "status": "pending"
  },
  "message": "上传成功，等待管理员审核"
}
```

### 3. 前端 - 上传界面

**管理端**：
- 在知识库管理页面添加"上传文件"按钮
- 弹窗形式上传，支持选择分类和标签
- 上传成功后显示解析结果

**用户端**：
- 在知识库列表页添加"上传知识"入口
- 上传后提示"等待审核"

## 权限控制

| 用户类型 | 上传权限 | 审核权限 |
|----------|----------|----------|
| 普通用户 | 可上传，知识状态为 pending | 无 |
| 管理员 | 可上传，知识直接生效 | 可审核用户上传的知识 |

## 数据库修改

**Knowledge 模型新增字段**：
```python
class Knowledge(db.Model):
    # 新增字段
    status = db.Column(db.String(20), default='active')  # active/pending/rejected
    uploader_id = db.Column(db.Integer, db.ForeignKey('user.id'))  # 上传者ID
    file_path = db.Column(db.String(500))  # 原始文件路径
```

## API 汇总

| 方法 | 路径 | 描述 | 权限 |
|------|------|------|------|
| POST | /api/admin/knowledge/upload | 管理员上传文件 | 管理员 |
| POST | /api/knowledge/upload | 用户上传文件 | 登录用户 |
| GET | /api/admin/knowledge/pending | 获取待审核知识列表 | 管理员 |
| PUT | /api/admin/knowledge/pending/:id | 审核通过/拒绝 | 管理员 |

## 验收标准

1. ✅ 管理员可上传 PDF/DOCX/TXT/MD 文件
2. ✅ 用户可上传文件，状态为待审核
3. ✅ 文件内容正确解析并存储
4. ✅ 管理员可查看待审核列表并审核

## 技术栈

- Flask + SQLAlchemy
- python-docx（DOCX解析）
- PyPDF2（PDF解析）
- Vue 3 + Element Plus
