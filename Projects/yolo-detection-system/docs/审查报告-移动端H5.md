# 移动端 H5 代码审查报告（日期 2026-10-30）

- 审查对象：`mobile/`（uni-app Vue3，H5 为主），范围 `src/pages/`、`src/api/`、`src/store/`、`src/utils/`、`src/App.vue`
- 契约基准：`backend/routes/**`（Flask，统一 HTTP 200 + `code` 业务码，成功 `code=0`）
- 审查方式：只读静态审查，未修改任何代码
- 统计：共 25 条（高 4 / 中 4 / 低 17）

| 文件#行号 | 等级 | 描述 | 建议 |

## 5. token 过期处理、请求错误处理统一性

| 文件#行号 | 等级 | 描述 | 建议 |
|---|---|---|---|
| src/api/request.js#45-49 | 高 | `code===401` 分支只 `handleTokenExpired()` + reject，**不 toast 后端 message**；而后端登录失败同样返回 `code=401`（backend/routes/auth.py#63），`handleTokenExpired` 在登录页提前 return（src/utils/error.js#29），导致**登录页输错密码完全无任何提示**（login/index.vue#101-103 注释假设 request.js 已提示） | 401 分支先 toast 后端 message；或由 handleTokenExpired 统一 toast 且登录页不拦截文案 |
| src/api/request.js#44-49 + src/utils/error.js#25-42 | 低 | 非登录页 token 过期时 handleTokenExpired toast 一次，页面 catch 再 showError 一次，出现双重提示 | reject 的 Error 携带 `handled` 标记，页面 catch 识别后跳过 showError |
| src/api/request.js#72-78 | 低 | 后端框架级错误（404/500，backend/app.py#124-140）走真实 HTTP 状态码，前端只提示"网络错误 404/500"，丢失后端 message | statusCode 异常分支优先读 `res.data.message` |
