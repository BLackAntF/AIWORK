# 番茄病害检测系统 — 功能清单与操作手册

> 更新日期：2026-10-12 ｜ 版本 v1.0（对应模型 yolo26n-tomato，200 轮训练版）
> 本文档基于实际代码路由与页面整理，覆盖 Web 端 / H5 移动端 / 管理端全部功能。

---

## 一、系统概览

| 端 | 地址 | 说明 |
|----|------|------|
| Web 端 | http://localhost:5173 | 桌面浏览器，功能最全 |
| H5 移动端 | http://localhost:5174 | 手机浏览器 / 真机调试（局域网访问 `http://电脑IP:5174`） |
| 后端 API | http://localhost:5000 | Flask + 真实 YOLO 模型推理 |
| App | 真机打包指南-1012.md | HBuilderX 云打包，同 H5 功能 |

**账号**：演示管理员 `admin / password123`；普通用户通过注册页创建。管理员登录后自动进入管理端。
**角色**：`admin`（管理端全部功能）、普通用户（检测/问答/知识库/历史/个人中心）。

## 二、用户端功能清单

### 1. 注册与登录

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 注册 | Web `/register`；H5 登录页底部「注册」 | ① 填写用户名、密码（两遍）→ ② 提交后自动登录进入系统。普通用户注册即可用，无需管理员审批 |
| 登录 | Web `/login`；H5 启动即登录页 | ① 输入用户名/密码 → ② 点「登录」。登录态保持 24 小时（JWT） |
| 退出登录 | 右上角头像菜单；H5「我的」页 | 点击「退出登录」清除本地令牌 |

### 2. 智能检测（核心功能）

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 单图检测 | Web `/detect`；H5 底部「检测」Tab | ① 点「上传图片」或拖拽图片到上传区（支持 png/jpg/jpeg/bmp/webp，单张 ≤100MB）→ ② 等待推理（首张约 10s 含模型加载，之后约 0.4s/张）→ ③ 查看结果：病害类别、置信度、检测框标注图 |
| 批量检测 | Web `/detect` 批量上传入口 | ① 一次选择多张（单次最多 20 张）→ ② 系统逐张推理 → ③ 结果列表展示每张的类别与置信度 |
| 查看检测详情 | 检测结果卡片「查看详情」或历史页记录 | 展示：原图与标注结果图对照、每个检测框的类别/置信度/位置、健康判定结论 |
| 查看病害档案 | 检测结果页联动入口；H5 检测页「病害档案」 | 按检测出的病害类别自动关联：病害症状、发生规律、农业防治、药剂防治（含**用药剂量**与**安全间隔期**）、生物防治（10 类番茄病害档案）；字段由管理端维护，PDF 报告与 AI 问答同步引用 |
| 检测报告 | 历史记录详情页「导出报告」/「下载 PDF」 | 「导出报告」生成结构化 HTML 报告（结论 + 置信度 + 处置建议）；「下载 PDF」导出正式版 PDF 文件（含检测明细表、病害档案四节、结果标注图、用药剂量与安全间隔期，可直接打印存档） |
| 低置信度兜底 | 检测结果页自动提示（Web / H5） | 当最高置信度低于阈值（默认 0.5）时：① 显示黄色警示条，提示重新拍摄清晰叶片照片 → ② 列出 top3 候选类别及各自置信度 → ③ 该图片自动收录进样本池待人工复核（不重复收录）；用户仍可手动提交「检测反馈」覆盖自动记录 |

> 视频检测：Web 端不提供（按项目规划预留移动 App 后续实现）。

### 3. 检测历史

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 历史列表 | Web `/history`；H5 底部「历史」Tab | 自动按时间倒序展示本人全部检测记录（文件名、类别、置信度、时间）；支持按病害类别/时间范围筛选、关键词搜索、分页 |
| 历史统计 | Web `/history` 顶部统计卡 | 显示累计检测总数、健康叶片数、病害叶片数 |
| 记录详情 | 列表点击任意记录 | 查看该次检测完整结果与标注图 |
| 删除记录 | 详情页/列表「删除」 | 单条删除；「清空」按钮删除本人全部记录（不可恢复，谨慎操作） |
| 导出 CSV | Web `/history`「导出」按钮 | 导出当前筛选结果为 CSV 文件（上限 5000 行），可用 Excel 打开 |
| 检测反馈 | H5 检测详情页「检测反馈」按钮 | ① 弹窗选择反馈类型：标注正确 / 识别错误 / 漏检 / 不确定 → ② 选「识别错误」时填写正确类别，可补充说明 → ③ 提交后进入管理员样本池（同一记录限提一次）；审核通过后归档为训练数据，用于持续改进模型 |
| AI 问诊 | Web/H5 检测详情页「AI 问诊」按钮 | 一键跳转 AI 问答并自动带入该次检测结果（病害类别 + 置信度 + 结果图），直接追问防治方案 |
| 分享检测结果 | Web 检测详情页「分享」按钮 | ① 生成只读分享链接与二维码（默认 7 天有效，可设 1~30 天）→ ② 复制链接或让农技员扫码 → ③ 对方**无需登录**即可查看结果图、检测明细与病害档案，页面不暴露用户名等隐私 |

### 4. AI 问答

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 对话提问 | Web `/knowledge`；H5 底部「AI问答」Tab | ① 在输入框输入问题（如"番茄叶片出现黄褐色斑点怎么办"）→ ② 回车发送 → ③ AI 结合知识库回答；每分钟提问上限 20 次 |
| 多会话管理 | 问答页左侧会话列表 | 「新会话」另起话题；点击切换历史会话；删除不需要的会话 |
| 引用知识 | 回答附带的引用卡片 | 点击回答下方引用的知识条目跳转知识详情 |
| 带检测上下文提问 | 检测详情页/检测页「AI 问诊」 | 自动带入检测到的病害类别与置信度，快捷提问已预填（如"早疫病怎么防治？"），AI 按具体病害作答 |

> 当前 LLM 处于 Mock 模式（`LLM_USE_MOCK=true`），回答为内置话术；接入真实大模型 API 后自动生效。

### 5. 知识库

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 浏览知识 | Web `/knowledge-list`；H5「知识库」页 | 按分类/标签筛选，点标题进入知识详情（详情页含相关推荐） |
| 收藏知识 | 知识详情页「收藏」按钮 | 收藏后可在「我的收藏」查看；再次点击取消收藏 |
| 投稿知识 | Web 知识库页「上传投稿」 | ① 上传文档（txt/md/pdf/docx）→ ② 系统自动解析标题与摘要 → ③ 选择分类/标签提交 → ③ 进入「待审核」状态，管理员审核通过后全站可见 |

### 6. 通知中心

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 查看通知 | Web `/notifications`；H5「通知」入口 | 列表展示系统通知（如投稿审核结果），顶部显示未读数角标 |
| 标记已读 | 通知条目点击 | 单条标记已读；「全部已读」一键清零 |
| 删除通知 | 通知条目「删除」 | 仅删除该条 |

### 7. 个人中心

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 修改密码 | Web `/profile`；H5「我的 → 修改密码」 | ① 输入旧密码 → ② 新密码两遍 → ③ 提交后需用新密码重新登录 |
| 查看个人信息 | Web `/profile` | 显示用户名、角色、注册时间、检测次数等 |

## 三、管理端功能清单（admin 角色）

登录管理员账号后，Web 端访问 `/admin/*`；H5 端「我的」页有管理入口（用户管理/待审核/操作日志/数据看板）。

### 1. 管理概览

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 数据看板 | Web `/admin/dashboard` | 无需操作，自动展示：用户总数/今日活跃、检测总数、知识库条数、近 7 天检测趋势等核心指标 |

### 2. 用户管理

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 用户列表 | `/admin/users` | 查看全部用户（含其检测数/知识数）；支持搜索、分页 |
| 启用/禁用 | 用户行「状态」开关 | 禁用后该用户无法登录 |
| 修改角色 | 用户行「角色」下拉 | 在 admin / user 间切换（谨慎授权） |
| 删除用户 | 用户行「删除」 | 二次确认后删除该用户及其关联数据 |
| 用户统计 | `/admin/users` 统计卡 | 总用户数、活跃用户数 |

### 3. 知识库管理（含审核）

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 知识列表 | `/admin/knowledge` | 查看全站知识条目（含用户投稿）；支持按分类/状态筛选 |
| 审核投稿 | `/admin/knowledge` 筛选「待审核」；H5「待审核」页 | 对 pending 状态投稿点「通过」（上线全站可见）或「驳回」（通知作者） |
| 新增/编辑知识 | 列表「新增」/行「编辑」 | 填写标题、正文、分类、标签、来源 |
| 删除知识 | 行「删除」 | 二次确认 |

### 4. 检测记录管理

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 全站检测记录 | `/admin/detections` | 查看所有用户的检测记录；支持按用户/类别/时间筛选 |
| 类别分布 | 页面顶部统计区 | 各病害类别检出次数分布（2026-10-12 起已正确显示类别名） |
| 删除记录 | 行「删除」/「批量删除」 | 管理员可清理任意记录 |

### 5. 数据统计

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 检测趋势 | `/admin/stats` | 按日/周/月查看检测量趋势图 |
| 用户趋势 | 同页 | 新增用户与活跃用户趋势 |
| 病害分布/趋势 | 同页 | 各病害检出占比与随时间变化（辅助研判病害流行） |
| 统计导出 | 「导出」按钮 | 导出统计数据 CSV |
| 数据大屏 | `/admin/screen` 或菜单「数据大屏」 | 深色可视化大屏：实时时钟、用户/检测/知识库/今日检测四指标卡、近 7 天检测趋势、病害类别分布、用户增长三图表；点「进入全屏」投屏展示，再点退出 |

### 6. 模型版本对比

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 版本概览 | `/admin/model-compare` | 每个模型版本一张统计卡：检测总数、病害/健康占比、无检出、平均置信度、使用时段 |
| 明细对比 | 同页表格 | 各版本检测数/病害数/健康数/无检出/置信度/最早与最近使用时间横向对比 |
| 类别分布对比 | 同页柱状图 | 各版本 Top 类别检出分布分组柱状图，直观比较模型迭代效果（如 mock-yolo26s → yolo26n-tomato） |

### 7. 样本池审核（增量训练数据）

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 反馈列表 | `/admin/sample-pool` 或菜单「样本池」 | 查看用户提交的检测反馈（样本图/反馈类型/纠正类别/预测结果/备注），按待审核/已通过/已驳回筛选，徽标显示各状态数量 |
| 审核样本 | 待审核行「通过」/「驳回」 | 「通过」确认纳入训练数据集；「驳回」填写原因（自动通知提交者，如"该记录已提交过反馈"类重复项） |
| 导出训练包 | 右上「导出训练数据包」 | 下载 zip：`images/<最终类别>/` 按类别归档样本图 + `metadata.csv` 清单 + README（图片为检测框标注图，需用 LabelImg 人工重标后接入 YOLO 训练） |

### 8. 系统配置（运维）

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 参数配置 | `/admin/config` | 查看/修改系统键值配置（如置信度阈值相关开关），保存即生效 |
| 模型管理 | `/admin/config` 模型区 | ① 「上传模型」选择 `.pt` 权重文件 → ② 在模型列表点「激活」切换当前推理模型 → ③ 生效于下一次检测（当前激活：yolo26n-tomato，mAP50=95.8%） |

### 9. 操作日志

| 功能 | 入口 | 操作步骤 |
|------|------|----------|
| 审计日志 | `/admin/operation-logs`；H5「操作日志」 | 查看敏感操作（登录/删除/审核/配置变更等）的操作人、时间、IP；支持筛选，只读 |

## 四、H5 / App 与 Web 端的功能差异

| 功能 | Web | H5/App |
|------|-----|--------|
| 单图检测（拍照/相册） | ✅ 上传 | ✅ 拍照或相册选图 |
| 批量检测 | ✅ | ❌（单图为主） |
| 检测报告导出 CSV / PDF | ✅ CSV + PDF | ❌ |
| 详情页 AI 问诊（带检测结果上下文） | ✅ | ✅ |
| 检测反馈（样本池） | ❌ | ✅ 详情页弹窗提交 |
| 低置信度兜底提示（top3 候选 + 自动进样本池） | ✅ | ✅ |
| 分享检测结果（链接 + 二维码） | ✅ | ❌ |
| 天气与施药建议（近 5 天） | ❌ | ✅ 首页卡片 |
| AI 问答 / 知识库 / 收藏 / 投稿 | ✅ | ✅ |
| 通知中心 | ✅ | ✅ |
| 管理端 | ✅ 全部（含模型对比/样本池/数据大屏） | ✅ 精简（用户/待审核/日志/看板） |
| 视频检测 | ❌（预留 App） | ❌（预留） |

> H5 真机注意：手机与电脑同一 WiFi；电脑防火墙放行 5000 端口；App 内 API 地址构建时写入（换网络需重新构建）。

## 五、快速启动（开发环境）

```bash
# 1. 后端（端口 5000）
cd backend && python app.py

# 2. Web 前端（端口 5173）
cd frontend && npm run dev

# 3. H5（端口 5174）
cd mobile && npm run dev:h5
```

| 常见问题 | 说明 |
|----------|------|
| 检测报"无检出" | 图片置信度低于 0.5；可在管理端调整阈值或换更清晰的单叶片图 |
| 手机访问不了后端 | 检查同 WiFi、防火墙 5000 端口、后端已启动 |
| AI 回答是固定话术 | LLM Mock 模式，配置 `LLM_API_KEY`/`LLM_BASE_URL` 后关闭 `LLM_USE_MOCK` |
| 模型切换 | 管理端 → 系统配置 → 模型管理 → 激活目标权重 |
