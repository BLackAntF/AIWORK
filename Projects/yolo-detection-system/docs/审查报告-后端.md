## 建议优先处理 Top 5

1. **routes/history.py#731 `is_healthy` 未定义崩溃**（高）：任何"无检出目标"的记录点 PDF 报告必 500，影响线上可用性，改一行即可修。
2. **routes/admin/sample_pool.py#127 样本导出恒缺图**（高）：`image_path` 存 URL 却按磁盘路径判断，训练数据包导出功能整体失效，增量训练闭环断裂。
3. **routes/knowledge.py 与 knowledge_user.py 路由冲突 + 公开接口泄漏 `file_path`**（高/中）：三条公开路由实际不可达，且生效版本把服务器绝对路径暴露给匿名用户。
4. **init_db.py#29-54 硬编码 `password123` 且强制重置 admin 密码**（高）：脚本在生产环境一旦执行即留后门，需改为环境变量驱动且不再无条件重置。
5. **routes/auth.py#50 登录无频率限制**（中）：可无限爆破密码，配合默认弱密码风险叠加，建议尽快加登录限流。
