# 知识库用户端页面 - 0707

## 任务类型
前端开发

## 需求描述

为番茄叶片病害检测系统添加用户端知识库页面，让普通用户可以浏览、搜索和查看知识详情。

## 功能需求

### 1. 知识库列表页（KnowledgeList.vue）

**路由**：`/knowledge`

**功能**：
- 展示所有已发布的知识文章列表
- 支持分类筛选（可选分类：病害识别、防治方法、栽培技术、基础知识）
- 支持关键词搜索（标题和内容模糊匹配）
- 列表展示：标题、分类标签、摘要、发布时间、阅读量
- 分页功能（每页12条）

**页面布局**：
- 顶部：页面标题 + 搜索框
- 筛选栏：分类标签按钮（全部、病害识别、防治方法、栽培技术、基础知识）
- 知识卡片网格（PC端3列，移动端1列）
- 底部：分页器

### 2. 知识详情页（KnowledgeDetail.vue）

**路由**：`/knowledge/:id`

**功能**：
- 展示文章完整内容
- Markdown 渲染（使用已有 marked 库）
- 返回按钮
- 相关推荐（同分类下的其他文章，可选）

**页面布局**：
- 顶部：返回按钮
- 标题区：标题、分类、发布时间、阅读量
- 内容区：Markdown 渲染后的 HTML

## API 接口

### 获取知识列表
```
GET /api/knowledge/list
Query参数：
  - page: 页码（默认1）
  - page_size: 每页条数（默认12）
  - category: 分类筛选（可选）
  - keyword: 搜索关键词（可选）
Response:
{
  "code": 200,
  "data": {
    "items": [
      {
        "id": 1,
        "title": "番茄早疫病识别与防治",
        "category": "disease",
        "summary": "番茄早疫病是番茄常见病害之一...",
        "content": "## 症状\n...",
        "views": 156,
        "created_at": "2026-07-01T10:00:00"
      }
    ],
    "total": 50,
    "page": 1,
    "page_size": 12
  }
}
```

### 获取知识详情
```
GET /api/knowledge/:id
Response:
{
  "code": 200,
  "data": {
    "id": 1,
    "title": "番茄早疫病识别与防治",
    "category": "disease",
    "content": "## 症状\n...",
    "views": 157,
    "created_at": "2026-07-01T10:00:00"
  }
}
```

## 已有组件复用

- `marked` 库：Markdown 渲染
- 分类标签组件：参考 Knowledge.vue 中的实现
- 卡片样式：参考 Dashboard.vue 中的统计卡片样式

## 后端配合

后端需要新增/修改接口：
- 修改 `/api/knowledge/list` 支持分页和筛选
- 修改 `/api/knowledge/:id` 返回完整内容
- 添加 `views` 阅读量字段

## 验收标准

1. 用户可以访问 `/knowledge` 页面查看知识列表
2. 可以按分类筛选知识
3. 可以搜索知识（标题关键词）
4. 可以点击知识卡片进入详情页
5. 详情页正确渲染 Markdown 内容
6. 页面适配移动端
