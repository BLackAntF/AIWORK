# 0705-前端任务

## 任务概述
实现病害档案前端展示：在检测结果页面展示病害档案卡片，新增"咨询此病害"按钮，AI问答组件传递 detected_class_id 参数。

---

## 1. 检测结果页面展示病害档案

**文件**：`frontend/src/views/user/DetectionResult.vue`（或相关页面）

在检测结果区域下方新增病害档案卡片，使用 `el-descriptions` 组件展示：

```vue
<template>
  <!-- 检测结果卡片 -->
  <div v-for="(result, index) in detectionResults" :key="index" class="detection-item">
    <el-card class="result-card">
      <!-- 原有检测结果展示 -->
      <div class="result-info">
        <span class="class-name">{{ result.class_name }}</span>
        <span class="confidence">{{ (result.confidence * 100).toFixed(1) }}%</span>
      </div>

      <!-- 病害档案卡片 -->
      <div v-if="result.disease_profile" class="disease-profile-section">
        <el-card shadow="hover">
          <template #header>
            <div class="card-header">
              <span>病害档案</span>
              <el-tag type="info">{{ result.disease_profile.disease_name }}</el-tag>
            </div>
          </template>

          <el-descriptions :column="1" border size="small">
            <el-descriptions-item label="诱因">
              {{ result.disease_profile.causes }}
            </el-descriptions-item>
            <el-descriptions-item label="典型症状">
              {{ result.disease_profile.symptoms }}
            </el-descriptions-item>
            <el-descriptions-item label="发生规律">
              {{ result.disease_profile.occurrence || '暂无' }}
            </el-descriptions-item>
            <el-descriptions-item label="预防措施">
              {{ result.disease_profile.prevention }}
            </el-descriptions-item>
            <el-descriptions-item label="治疗方案">
              {{ result.disease_profile.treatment }}
            </el-descriptions-item>
            <el-descriptions-item label="推荐药剂">
              {{ result.disease_profile.pesticides }}
            </el-descriptions-item>
          </el-descriptions>

          <!-- 咨询按钮 -->
          <div class="action-buttons">
            <el-button type="primary" @click="askAboutDisease(result)">
              咨询此病害
            </el-button>
          </div>
        </el-card>
      </div>

      <!-- 健康叶片不显示档案和咨询按钮 -->
      <div v-else-if="result.class_name === 'Healthy'" class="healthy-info">
        <el-tag type="success" size="large">健康叶片</el-tag>
        <p>该叶片未检测到病害特征，继续保持良好管理。</p>
      </div>
    </el-card>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const detectionResults = ref([])

const askAboutDisease = (result) => {
  // 触发父组件或使用事件总线，打开AI问答并传递上下文
  emit('open-chat', {
    detected_class_id: result.class_id,
    disease_name: result.disease_profile?.disease_name,
    detection_context: `${result.class_name} (${(result.confidence * 100).toFixed(1)}%)`
  })
}

const emit = defineEmits(['open-chat'])
</script>

<style scoped>
.disease-profile-section {
  margin-top: 16px;
}

.card-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.action-buttons {
  margin-top: 16px;
  text-align: center;
}

.healthy-info {
  margin-top: 16px;
  text-align: center;
}
</style>
```

## 2. AI 问答组件传递参数

**文件**：`frontend/src/components/ChatAssistant.vue`（或相关组件）

修改问答接口调用，当有检测上下文时传递 `detected_class_id`：

```javascript
const chatState = reactive({
  detectedClassId: null,
  diseaseName: '',
  detectionContext: ''
})

const sendMessage = async () => {
  if (!userInput.value.trim()) return

  const params = {
    question: userInput.value,
    session_id: currentSessionId
  }

  // 如果有检测上下文，传递额外参数
  if (chatState.detectedClassId !== null) {
    params.detected_class_id = chatState.detectedClassId
    params.detection_context = chatState.detectionContext
  }

  try {
    const res = await request.post('/api/knowledge/ask', params)
    // 处理响应...
  } catch (error) {
    // 错误处理...
  }
}

// 暴露给外部调用的方法
const setDetectionContext = (context) => {
  chatState.detectedClassId = context.detected_class_id
  chatState.diseaseName = context.disease_name
  chatState.detectionContext = context.detection_context
}

defineExpose({
  setDetectionContext
})
```

## 3. 页面集成（可选）

**方式一**：如果检测结果页面和AI问答在同一个页面，通过 props/events 通信。

**方式二**：如果AI问答是全局组件（如抽屉/弹窗），可在路由跳转时携带参数，或使用 Pinia/Vuex 共享状态。

**示例（使用 Pinia）**：

```javascript
// stores/chat.js
import { defineStore } from 'pinia'

export const useChatStore = defineStore('chat', {
  state: () => ({
    detectedClassId: null,
    diseaseName: '',
    detectionContext: '',
    chatVisible: false
  }),
  actions: {
    setContext(context) {
      this.detectedClassId = context.detected_class_id
      this.diseaseName = context.disease_name
      this.detectionContext = context.detection_context
    },
    openChat() {
      this.chatVisible = true
    }
  }
})
```

## 注意事项

1. 检测结果中没有 `disease_profile` 时（模型未识别或出错），不显示档案卡片
2. `class_name === 'Healthy'` 时显示"健康"提示，不显示咨询按钮
3. 确保 `detected_class_id` 传递为整数类型
4. 样式保持与项目现有组件风格一致
