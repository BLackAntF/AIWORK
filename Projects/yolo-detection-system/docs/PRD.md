# 番茄叶片病害智能诊断平台 PRD

## 1. 产品概述

### 1.1 产品简介

**番茄叶片病害智能诊断平台**是一款基于深度学习的目标检测算法（YOLO26）和大语言模型（LLM）的农业智能化应用。系统可对番茄叶片图像进行智能分析，自动识别10种常见番茄叶片病害，并提供病害档案查询、AI智能问答、防治建议等功能。

### 1.2 产品定位

- **目标用户**：番茄种植户、农业技术人员、农业生产合作社
- **核心价值**：提升病害识别效率，降低经济损失，提供科学的防治建议
- **差异化优势**：检测+档案+AI问答一体化，保证回答一致性

### 1.3 名词定义

| 术语 | 定义 |
|------|------|
| YOLO26 | Ultralytics 2026年发布的最新目标检测模型 |
| 病害档案 | 结构化的病害信息（诱因/症状/防治方案等） |
| RAG | 检索增强生成，AI问答技术方案 |
| Mock模式 | 开发环境使用模拟数据，非真实LLM调用 |

## 2. 功能需求

### 2.1 用户端功能

#### 2.1.1 用户认证
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 用户注册 | 输入用户名、邮箱、密码进行注册 | P0 |
| 用户登录 | 输入账号密码登录 | P0 |
| 修改密码 | 登录后修改个人密码 | P1 |
| 退出登录 | 清除登录状态 | P0 |

#### 2.1.2 图像检测
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 图片上传 | 支持上传PNG/JPG/JPEG/BMP/WEBP格式，单文件≤10MB | P0 |
| 智能检测 | 调用YOLO26模型识别病害，返回检测结果 | P0 |
| 结果展示 | 在原图上绘制检测框，显示类别名称、置信度 | P0 |
| 结果保存 | 保存检测记录到数据库，可查看历史 | P0 |

**检测的病害类别（class_id: 0-9）**：
| ID | 英文名 | 中文名 |
|----|--------|--------|
| 0 | BacterialSpot | 细菌性斑点病 |
| 1 | EarlyBlight | 早疫病 |
| 2 | Healthy | 健康叶片 |
| 3 | LateBlight | 晚疫病 |
| 4 | LeafMold | 叶霉病 |
| 5 | MosaicVirus | 花叶病毒病 |
| 6 | SeptoriaLeafSpot | 斑枯病 |
| 7 | SpiderMites | 蜘蛛螨危害 |
| 8 | TargetSpot | 靶斑病 |
| 9 | YellowLeafCurlVirus | 黄化曲叶病毒病 |

#### 2.1.3 病害档案
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 档案展示 | 检测后自动展示病害档案卡片 | P0 |
| 档案内容 | 诱因、症状、发生规律、预防措施、治疗方案、推荐药剂 | P0 |
| 健康提示 | Healthy类别显示"叶片健康"提示 | P0 |

#### 2.1.4 AI智能问答
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 咨询病害 | 检测后可一键咨询已识别的病害 | P0 |
| 自由问答 | 用户可输入任何农业相关问题 | P0 |
| 对话历史 | 保存用户对话记录，支持查看历史会话 | P1 |
| 会话管理 | 支持新建会话、切换会话、删除会话 | P1 |

**AI问答数据来源**：
1. **病害档案**（优先级最高）- 结构化数据，保证一致性
2. **知识库**（补充）- 管理员添加的泛化知识
3. **检测上下文**（可选）- 当前检测结果

#### 2.1.5 检测历史
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 历史列表 | 展示用户所有检测记录 | P1 |
| 详情查看 | 查看历史检测的详细信息和结果 | P1 |
| 结果删除 | 删除单条检测记录 | P2 |

#### 2.1.6 知识库
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 知识浏览 | 查看知识库文章列表 | P1 |
| 分类筛选 | 按分类筛选知识 | P2 |
| 关键词搜索 | 搜索知识库内容 | P2 |
| 知识详情 | 查看知识文章详情 | P1 |

## 3. 非功能需求

### 3.1 性能需求
| 指标 | 要求 |
|------|------|
| 图片检测响应时间 | ≤3秒（不含模型加载时间） |
| 页面加载时间 | ≤2秒 |
| API响应时间 | ≤500ms |
| 并发用户数 | ≥50 |

### 3.2 安全需求
| 需求 | 说明 |
|------|------|
| 密码加密 | 使用pbkdf2:sha256加密 |
| JWT认证 | 接口调用需携带有效Token |
| 权限控制 | 管理员接口需admin角色 |
| SQL注入防护 | 使用参数化查询 |
| 文件上传限制 | 仅允许图片格式，限制大小 |

### 3.3 兼容性需求
| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome/Firefox/Edge/Safari最新两个版本 |
| 屏幕适配 | 响应式设计，支持1024px以上屏幕 |
| 移动端 | 基础适配，不作为主要使用场景 |
