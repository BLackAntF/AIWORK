# 番茄叶片病害智能诊断平台 PRD

## 1. 产品概述

### 1.1 产品简介

**番茄叶片病害智能诊断平台**是一款基于深度学习的目标检测算法（YOLO26）和大语言模型（LLM）的农业智能化应用。系统可对番茄叶片图像进行智能分析，自动识别10种常见番茄叶片病害，并提供病害档案查询、AI智能问答、防治建议等功能。

平台包含 Web 端和移动端 App（uni-app）两种形态：
- **Web 端**：面向管理后台场景（知识库管理、用户管理、数据统计等），在桌面浏览器中使用
- **移动端 App**：面向田间场景（拍照检测、查看结果、病害档案、AI问答），在手机上使用

### 1.2 产品定位

- **目标用户**：番茄种植户（田间使用 App）、农业技术人员（办公室使用 Web）、农业生产合作社
- **核心价值**：提升病害识别效率，降低经济损失，提供科学的防治建议
- **差异化优势**：检测+档案+AI问答一体化，AI 回答以病害档案为准，保证回答一致性

### 1.3 名词定义

| 术语 | 定义 |
|------|------|
| YOLO26 | Ultralytics 2026年发布的最新目标检测模型 |
| 病害档案 | 结构化的病害信息（诱因/症状/防治方案等） |
| RAG | 检索增强生成，AI问答技术方案 |
| Mock模式 | 开发环境使用模拟数据，非真实LLM调用 |
| uni-app | 跨平台前端框架，一套代码发布到多端（App/小程序/H5） |
| 多模态问答 | AI问答支持同时输入图片和文本，结合检测结果图片和病害档案回答 |

**AI问答架构（RAG）**：

```
用户问题 + 检测图片（可选）
        │
        ▼
┌─────────────────┐
│  检索病害档案   │  ← 根据检测结果/问题关键词匹配对应病害档案
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  构建Prompt      │  ← 档案内容（权威源）+ 用户问题 + 图片（多模态）
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  LLM 生成回答   │  ← 以档案为准，LLM 补充扩展
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  输出回答列表    │  ← 每条回答附带置信度（高/中/低）
└─────────────────┘
```

**回答权威性规则**：
1. **档案优先**：病害档案中的内容为权威源，LLM 回答不得与档案矛盾
2. **冲突处理**：当 LLM 回答与档案冲突时，以档案为准，LLM 内容被过滤或标注"仅供参考"
3. **置信度展示**：回答以列表形式展示，每条附带置信度（高=档案原文/高匹配，中=LLM基于档案推理，低=LLM自有知识）
4. **超范围问题**：用户提问超出10种病害范围时，结合检测图片上下文尝试回答，无法回答时明确提示"该问题超出当前知识范围"

**AI问答数据来源**（按优先级）：
1. **病害档案**（最高优先级）- 结构化数据，保证回答一致性
2. **检测图片**（多模态）- 用户检测后的图片可直接传入，AI 结合图片和档案回答
3. **知识库**（补充）- 管理员添加的泛化知识
4. **检测上下文**（可选）- 当前检测结果（病害名称、置信度等）

## 3. 非功能需求

### 3.1 性能需求
| 指标 | 要求 | 备注 |
|------|------|------|
| 图片检测响应时间 | ≤3秒（不含模型加载时间） | 待真实模型接入后实测验证 |
| AI 问答响应时间 | ≤5秒（含 RAG 检索 + LLM 生成） | 多模态（含图片）可能更慢 |
| 页面加载时间 | ≤2秒 | Web 端 |
| App 首屏加载 | ≤3秒 | uni-app |
| API响应时间 | ≤500ms | 不含 AI/检测接口 |
| 并发用户数 | ≥50 | Web + App 共享 |

> **注意**：以上性能指标均为目标值。图片检测和 AI 问答的实际性能取决于真实 YOLO 模型和 LLM API 的响应速度，需在模型接入后进行实测并调整。

### 3.2 安全需求
| 需求 | 说明 |
|------|------|
| 密码加密 | 使用pbkdf2:sha256加密 |
| JWT认证 | 接口调用需携带有效Token |
| 权限控制 | 管理员接口需admin角色 |
| SQL注入防护 | 使用参数化查询 |
| 文件上传限制 | 仅允许图片格式，限制大小 |

### 3.3 兼容性需求
| 项目 | 要求 |
|------|------|
| Web 浏览器 | Chrome/Firefox/Edge/Safari最新两个版本 |
| Web 屏幕适配 | 响应式设计，支持1024px以上屏幕 |
| App 系统 | Android 8.0+ / iOS 12.0+ |
| App 开发框架 | uni-app（Vue 3 语法） |
| App 发布形态 | Android APK / iOS IPA（暂不含小程序） |

| App 状态管理 | Pinia | 与 Web 端一致 |
| 后端框架 | Flask | Python Web框架，Web 和 App 共用 |
| ORM | SQLAlchemy | 数据库ORM |

| AI模型 | YOLO26 | 目标检测模型 |
