## 6. 未验证边界与明确不宣称事项

1. **实时天气**：只验证接口校验、缓存、Mock 网络和失败降级，未验证外部天气服务实时返回。
2. **外部 SMTP**：只验证真实发送代码路径、配置分支及 `FakeSMTP`，未验证真实邮箱投递。
3. **在线大模型**：当前未配置 API Key，本轮验证本地模板降级；不得写成通义千问在线 API 已验收。
4. **移动端真机**：H5、微信小程序和 App 构建通过，但未完成微信开发者工具、Android/iOS 真机、拍照、定位授权和分享扫码的真机回归；样本加载更多失败回滚页码也只完成代码与构建确认。Web 窄视口人工验收通过不代表移动端真机已验收。
5. **历史问答来源**：新问答已验证标题与知识 ID 契约且未新增 `ERR_ABORTED`；旧会话持久化的历史来源字符串不做批量回填，仍可能展示修复前的正文片段。
6. **专项运维平台**：未接入 CDN、Redis 共享限流、Sentry、Prometheus 或完整 APM；基础缓存、进程内限流和耗时日志不冒充这些平台能力。
7. **本轮未覆盖的破坏性操作**：未在真实数据中执行用户删除、批量历史删除、样本驳回、模型切换等操作；相关条目只标为代码确认或隔离测试。
8. **明确不实现**：病斑面积占比统计、病情分级、Web 视频实时检测不纳入当前系统功能；地块/作物病程跟踪亦不属于本次交付。
9. **实验目录边界**：本轮未修改 `training/` 和 `dataset/`，功能清单不将训练实验或模型指标包装成新增软件功能。
