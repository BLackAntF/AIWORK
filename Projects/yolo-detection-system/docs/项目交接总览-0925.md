## 三、项目规范与约束

**安全红线（必须遵守）**
- 禁止硬编码密钥 / API Key / 密码（用环境变量）
- 所有数据库查询必须参数化；用户输入必须校验
- 禁止 `eval`、字符串拼接 SQL；敏感操作必须权限校验

**工程规范**
- 函数不超过 20 行（单一职责）；用类型注解与 Docstring
- 禁止 Magic Value；第三方库需在白名单内
- AI 生成代码需人工 review，需有单元测试

**角色分工（按项目工作流）**
- 前端任务：用 `frontend-design` skill；后端任务：用 `backend-patterns` skill
- 审查任务：用 `TRAE-code-review` skill，报告存 `Reports/`
- 管理任务：只出报告与提示词、不写代码；负责 Git commit/push + 写日志

**Git 约定**
- 日志写入 `d:\Develop\CODE\AIWORK\Logs\git\YYYY-MM-DD.md`
- 项目文件放 `Projects/`，规范文件放 `Memory/`

**移动端约定**
- 技术栈 uni-app（Vue 3 Composition API + Pinia）
- API 层 `mobile/src/api/*.js` 是权威命名，页面必须与之一致
