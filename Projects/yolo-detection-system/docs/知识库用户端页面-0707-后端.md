# 知识库用户端页面 - 0707 后端任务

## 任务类型
后端开发

## 需求描述

为知识库用户端页面提供 API 支持，包括列表查询、详情查看等。

## 修改内容

### 1. 修改 Knowledge 模型

在 `backend/models.py` 的 Knowledge 类中添加字段：

```python
class Knowledge(db.Model):
    # ... 现有字段 ...
    
    summary = db.Column(db.String(500))  # 新增：摘要
    views = db.Column(db.Integer, default=0)  # 新增：阅读量
```

### 2. 新增用户端 API

**获取知识列表**（公开接口，不需要登录）
```
GET /api/knowledge/list
Query参数：
  - page: 页码（默认1）
  - page_size: 每页条数（默认12）
  - category: 分类筛选（可选：disease防治method/cultivation基础knowledge）
  - keyword: 搜索关键词（可选，匹配title和content）
Response:
{
  "code": 200,
  "data": {
    "items": [
      {
        "id": 1,
        "title": "番茄早疫病识别与防治",
        "category": "disease",
        "summary": "番茄早疫病是番茄常见病害之一...",
        "views": 156,
        "created_at": "2026-07-01T10:00:00"
      }
    ],
    "total": 50,
    "page": 1,
    "page_size": 12
  }
}
```

**获取知识详情**（公开接口，不需要登录）
```
GET /api/knowledge/:id
Response:
{
  "code": 200,
  "data": {
    "id": 1,
    "title": "番茄早疫病识别与防治",
    "category": "disease",
    "summary": "番茄早疫病是番茄常见病害之一...",
    "content": "## 症状\n...",
    "views": 157,
    "created_at": "2026-07-01T10:00:00"
  }
}
```

注意：详情接口需要自动增加阅读量（views +1）

**获取分类列表**（公开接口）
```
GET /api/knowledge/categories
Response:
{
  "code": 200,
  "data": {
    "categories": [
      {"value": "disease", "label": "病害识别"},
      {"value": "method", "label": "防治方法"},
      {"value": "cultivation", "label": "栽培技术"},
      {"value": "knowledge", "label": "基础知识"}
    ]
  }
}
```

### 3. 修改 knowledge_service.py

在 `list_knowledge` 方法中支持 keyword 搜索（模糊匹配 title 和 content）

## 分类映射

前端分类标签与数据库 category 字段对应：
- `disease` → 病害识别
- `method` → 防治方法
- `cultivation` → 栽培技术
- `knowledge` → 基础知识

## 验收标准

1. 用户端可访问 `/api/knowledge/list` 获取知识列表
2. 支持分页、分类筛选、关键词搜索
3. 用户端可访问 `/api/knowledge/:id` 获取详情
4. 访问详情时自动增加阅读量
5. 所有用户端接口不需要登录认证
