# 番茄叶片病害智能诊断平台 - 移动端 App 需求文档

> **版本**：v1.0
> **日期**：2026-07-14
> **关联 PRD**：PRD.md v2.0
> **技术框架**：uni-app（Vue 3 语法）

---

## 1. 文档目的

本文档定义移动端 App 的功能需求、页面结构、交互规范和验收标准，供开发实现参考。App 与 Web 端共用后端 API，本文档不重复后端接口定义，仅说明 App 端特有的交互和功能要求。

---

## 2. 产品定位

| 项目 | 说明 |
|------|------|
| 使用场景 | 田间/大棚现场，种植户拍照检测病害 |
| 核心设备 | 手机（Android 8.0+ / iOS 12.0+） |
| 与 Web 的关系 | App 是 Web 核心功能的移动延伸，管理操作以 Web 为主 |
| 网络要求 | 需要网络连接（暂不支持离线模式） |

---

## 3. 功能需求

### 3.1 用户认证

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|
| AUTH-01 | 登录 | 输入用户名+密码登录，获取 JWT Token | P0 |
| AUTH-02 | 注册 | 输入用户名、邮箱、密码注册新账号 | P0 |
| AUTH-03 | 退出登录 | 清除本地 Token 和用户信息 | P0 |
| AUTH-04 | 修改密码 | 登录后修改个人密码 | P2 |

**交互要求**：
- 登录页为 App 启动首屏（未登录状态）
- Token 存储在本地 Storage，启动时自动检查有效性
- Token 过期时自动跳转登录页

---

### 3.2 拍照检测

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|
| DET-01 | 相机拍照 | 调用系统相机拍摄番茄叶片照片 | P0 |
| DET-02 | 相册选择 | 从手机相册选择已有图片 | P0 |
| DET-03 | 图片预览 | 上传前预览选中的图片，支持重新选择 | P0 |
| DET-04 | 开始检测 | 上传图片到后端检测接口，显示加载状态 | P0 |
| DET-05 | 结果展示 | 展示检测结果图（带标注框）+ 病害名称+ 置信度 | P0 |
| DET-06 | 多结果展示 | 如果一张图检测到多种病害，展示所有结果列表 | P0 |
| DET-07 | 健康提示 | 检测结果为 Healthy 时显示"叶片健康" | P0 |

**交互要求**：
- 检测页为 TabBar 第二个 Tab
- 拍照/相册选择通过底部 ActionSheet 切换
- 图片压缩后再上传（控制大小 ≤5MB）
- 检测中显示全屏 Loading 或进度提示
- 检测失败时显示错误原因和重试按钮

**API 接口**：
- `POST /api/detect/image`（multipart/form-data，字段：image）

---

### 3.3 病害档案

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|
| ARCH-01 | 档案卡片 | 检测结果下方展示对应病害的档案卡片 | P0 |
| ARCH-02 | 档案详情 | 点击卡片进入档案详情页，展示完整信息 | P0 |
| ARCH-03 | 档案内容 | 展示：诱因、症状、发生规律、预防措施、治疗方案、推荐药剂 | P0 |
| ARCH-04 | 健康提示 | Healthy 类别显示健康养护建议 | P0 |

**交互要求**：
- 档案卡片在检测结果页直接展示（无需跳转）
- 档案详情页使用折叠面板（Collapse）展示各模块
- 推荐药剂用标签（Tag）样式展示

---

### 3.4 AI 智能问答

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|
| CHAT-01 | 文字提问 | 输入框输入问题，发送给 AI | P0 |
| CHAT-02 | 图片传入 | 检测后的图片可直接传入 AI 问答作为上下文 | P0 |
| CHAT-03 | 回答展示 | 以聊天气泡形式展示 AI 回答 | P0 |
| CHAT-04 | 置信度展示 | AI 回答以列表形式展示，每条附带置信度（高/中/低） | P0 |
| CHAT-05 | 快捷提问 | 检测后提供快捷问题按钮（如"这个病严重吗""怎么治"） | P1 |
| CHAT-06 | 会话列表 | 展示历史会话列表，可切换会话 | P1 |
| CHAT-07 | 新建会话 | 创建新的问答会话 | P1 |
| CHAT-08 | 删除会话 | 删除历史会话 | P2 |
| CHAT-09 | 输入限制 | 单条消息限制 500 字 | P0 |

**交互要求**：
- AI 问答为 TabBar 第三个 Tab
- 聊天界面底部为输入框 + 发送按钮
- 检测结果页有"咨询 AI"按钮，跳转到问答页并自动带入检测图片
- AI 回答中置信度用颜色区分：高（绿色）、中（橙色）、低（灰色）
- AI 思考中显示打字动画

**API 接口**：
- `POST /api/knowledge/ask`（字段：question, session_id, image_url）
- `GET /api/knowledge/sessions`（获取会话列表）
- `GET /api/knowledge/history?session_id=xxx`（获取会话消息）
- `DELETE /api/knowledge/session/<session_id>`（删除会话）

### 3.5 检测历史

| 功能ID | 功能名称 | 描述 | 优先级 |
|--------|----------|------|--------|
| HIST-01 | 历史列表 | 展示当前用户的所有检测记录，按时间倒序 | P1 |

| HIST-03 | 详情查看 | 点击列表项进入详情，查看完整检测结果和档案 | P1 |
| HIST-04 | 删除记录 | 滑动删除单条记录 | P2 |
| HIST-05 | 下拉刷新 | 下拉刷新历史列表 | P1 |
| HIST-06 | 上拉加载 | 上拉加载更多（分页） | P1 |

**API 接口**：
- `GET /api/history?page=X&page_size=Y`
- `GET /api/history/<id>`
- `DELETE /api/history/<id>`

## 4. 页面结构

### 4.1 TabBar 结构

| Tab | 图标 | 页面 | 说明 |
|-----|------|------|------|
| 首页 | home | pages/index/index | 快速入口 + 最近检测 |
| 检测 | camera | pages/detect/index | 拍照检测 |
| 问答 | chat | pages/chat/index | AI 问答 |
| 历史 | clock | pages/history/index | 检测历史 |
| 我的 | user | pages/mine/index | 个人中心 |

### 4.2 完整页面清单

```
pages/
├── index/index              ← 首页（TabBar）
├── detect/index             ← 检测（TabBar）
├── chat/index               ← AI问答（TabBar）
├── history/index            ← 历史（TabBar）
├── mine/index               ← 我的（TabBar）
├── login/index              ← 登录
├── register/index           ← 注册
├── archive/detail           ← 病害档案详情
├── history/detail           ← 历史检测详情
├── knowledge/list           ← 知识库列表
├── knowledge/detail         ← 知识详情
├── admin/users              ← 管理员-用户列表（只读）
├── admin/pending            ← 管理员-待审核（只读）
├── admin/logs               ← 管理员-操作日志（只读）
└── admin/dashboard          ← 管理员-数据看板（只读）
```

## 5. 交互规范

### 5.1 通用规范

| 项目 | 规范 |
|------|------|
| 加载状态 | 请求接口时显示 Loading 动画 |
| 错误处理 | 网络错误显示 Toast 提示，提供重试按钮 |
| 空状态 | 列表为空时显示空状态插画和文字说明 |
| 下拉刷新 | 列表页支持下拉刷新 |
| 上拉加载 | 列表页支持上拉加载更多 |
| Token 失效 | 401 时自动跳转登录页 |
| 图片加载 | 图片加载中显示占位图 |

### 5.2 主题配色

| 色值 | 用途 |
|------|------|
| #4CAF50 | 主色（绿色，农业主题） |
| #FF9800 | 辅助色（橙色，检测/警告） |
| #F44336 | 危险色（红色，删除/错误） |
| #2196F3 | 信息色（蓝色，AI 问答） |
| #9E9E9E | 灰色（低置信度/禁用） |

## 6. 技术约束

| 项目 | 约束 |
|------|------|
| 框架 | uni-app（Vue 3 + Composition API） |
| UI 组件库 | uView 或 uni-ui |
| 状态管理 | Pinia |
| 网络请求 | uni.request 封装（与 Web 端共用后端 API） |
| 图片上传 | uni.chooseImage + uni.uploadFile |
| 相机调用 | uni.chooseImage(sourceType: ['camera', 'album']) |
| 本地存储 | uni.setStorageSync / uni.getStorageSync |
| 图片压缩 | 上传前压缩到 ≤5MB |
| API 基地址 | 与 Web 端一致，通过环境变量配置 |

## 7. 验收标准

### 7.1 P0 功能验收

| 功能ID | 验收标准 |
|--------|----------|
| AUTH-01 | 输入正确账密可登录，Token 持久化，下次启动免登录 |
| AUTH-02 | 可注册新账号，注册后自动登录 |
| AUTH-03 | 退出后 Token 清除，跳转登录页 |
| DET-01 | 可调起系统相机拍照 |
| DET-02 | 可从相册选择图片 |
| DET-04 | 图片可上传到后端并返回检测结果 |
| DET-05 | 结果展示标注框、病害名称、置信度 |
| DET-06 | 多病害结果全部展示 |
| DET-07 | Healthy 显示健康提示 |
| ARCH-01 | 检测结果下方展示档案卡片 |
| ARCH-03 | 档案内容包含 6 个模块 |
| CHAT-01 | 可发送文字问题并收到 AI 回答 |
| CHAT-02 | 检测图片可传入问答 |
| CHAT-03 | 聊天气泡正确展示 |
| CHAT-04 | 回答列表附带置信度 |
| CHAT-09 | 输入超过 500 字时提示 |
| PROF-01 | 个人信息正确显示 |
| PROF-03 | 退出登录功能正常 |

### 7.2 兼容性验收

- Android 8.0+ 真机可正常运行
- iOS 12.0+ 真机可正常运行
- 拍照、相册、上传、网络请求功能正常
