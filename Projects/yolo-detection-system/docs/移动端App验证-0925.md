## 二、问题清单

### 问题 1：API 导入名不一致（致命，7 处）

`api/*.js` 的导出名是**正确的**（与后端、Web 端一致），是**页面导入用错了名字**。

| 页面 | 当前导入（错误） | 应改为 |
|------|-----------------|--------|
| `pages/chat/index.vue` | `getSessions` | `getSessionList` |
| `pages/chat/index.vue` | `createSession` | **删除**（后端无此接口，见问题 2） |
| `pages/knowledge/list.vue` | `getKnowledgeCategories` | `getCategories` |
| `pages/knowledge/detail.vue` | `getKnowledgeRelated` | `getRelatedKnowledge` |
| `pages/admin/users.vue` | `getAdminUsers` | `getUsers` |
| `pages/admin/pending.vue` | `getAdminPending` | `getPendingKnowledge` |
| `pages/admin/logs.vue` | `getAdminLogs` | `getLogs` |
| `pages/admin/dashboard.vue` | `getAdminDashboard` | `getDashboardStats` |

### 问题 2：响应结构不匹配

**统一说明**：页面在 `request.js` 中拿到的是 `res.data`（即后端的 `data` 字段），不是整个响应体。

| 位置 | 页面当前假设 | 后端实际返回 | 修复要求 |
|------|-------------|-------------|---------|
| chat 会话列表 | `data.items`，字段 `id/name/created_at` | `{sessions: [{session_id, title, last_message, last_time}]}` | 改用 `data.sessions`；模板字段改 `session_id`/`title`/`last_time` |
| chat 新建会话 | 调 `createSession()` 取 id | 无该接口；会话由 `POST /knowledge/ask` 隐式创建并返回 `session_id` | 删除 `createNewSession`，改为本地清空：`currentSessionId=''`、`messages=[]`；首次提问后用 `ask` 返回的 `session_id` 回填 |
| chat 聊天历史 | 未加载 | `GET /knowledge/history?session_id=` → `{list, total, page, page_size}` | 切换会话时用 `data.list` 渲染历史消息 |
| chat 置信度 | `msg.confidence` | `POST /knowledge/ask` 返回 `{answer, sources, session_id, session_title, disease_profile}`，**无 confidence** | 暂时不显示置信度标签（保留组件，待后端返回再加） |
| knowledge/list 分类 | `data` 为 `[{id,name}]` | `GET /knowledge/category-list` → `{categories: ["病害防治", ...]}`（字符串数组） | 改为 `data.categories`，每项映射为 `{id: name, name}`；全部项 `{id:'', name:'全部'}` |
| knowledge/list 列表项 | `item.category_id` + `getCategoryName()` | 列表项含 `category`（字符串）、`title`、`summary`、`created_at` | 直接用 `item.category` 显示，删除 `getCategoryName` |
| knowledge/list 筛选参数 | `params.category_id` | 后端参数名为 `category` | 改为 `params.category` |
| knowledge/detail 相关知识 | 直接把返回值当数组 | `GET /knowledge/{id}/related` → `{list, total}` | 改为 `relatedData.list` |
| admin/users 列表 | 待核对 | `{list, total, page, page_size}` | 使用 `data.list` |
| admin/pending 列表 | 待核对 | `{list, total, page, page_size}` | 使用 `data.list` |
| admin/logs 列表 | 待核对 | `{logs, total, page, page_size, pages}` | 使用 `data.logs` |
| admin/dashboard | 待核对 | `{total_users, total_detections, total_knowledge, total_chats, today_users, today_detections, today_chats}` | 使用上述扁平字段 |

### 问题 3：TabBar 点击（待人工确认）
浏览器 agent 点击底部 TabBar 后 URL 未变化，但直连页面 URL 均正常。**判断为 agent 点击定位问题，非真 Bug**。请在浏览器手动点击 TabBar 5 个页签确认。
