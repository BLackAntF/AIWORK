# 知识库质量优化 - 0708

## 任务类型
前后端联合开发

## 需求描述

优化知识库管理端功能，提升知识内容编辑体验。

---

## 一、富文本编辑器

### 前端需求

**位置**：管理端知识库添加/编辑页面

**功能**：
- 使用富文本编辑器替代当前的 Markdown 编辑器
- 支持富文本格式：加粗、斜体、下划线、标题、列表、链接、图片插入
- 富文本内容存储为 HTML 格式到数据库
- 前端用户端使用 v-html 渲染

**技术选型**：
- 推荐使用 `@vueup/vue-quill` 或 `wangeditor`
- 简单轻量：`wangeditor`（国产，文档友好）
- 功能强大：`@vueup/vue-quill`（基于 Quill）

**参考**：使用 wangeditor v5（https://www.wangeditor.com/）

### 后端需求

**修改 Knowledge 模型**：
```python
class Knowledge(db.Model):
    # 将 content 字段类型改为 Text（支持 HTML）
    content = db.Column(db.Text)  # 存储 HTML 格式
```

**注意**：
- 需要对用户提交的 HTML 进行 XSS 过滤
- 可以使用 `bleach` 库清理危险标签

## 二、标签系统

### 前端需求

**管理端**：
- 添加/编辑知识时，可选择或创建标签
- 标签输入支持自动补全（从已有标签中选择）
- 标签列表页面，支持增删改查

**用户端**：
- 知识列表页支持按标签筛选
- 标签云展示（可选）

### 后端需求

**新增 Tag 模型**：
```python
class Tag(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50), unique=True, nullable=False)
    color = db.Column(db.String(20), default='primary')
    created_at = db.Column(db.DateTime, default=datetime.utcnow)

class KnowledgeTag(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    knowledge_id = db.Column(db.Integer, db.ForeignKey('knowledge.id'))
    tag_id = db.Column(db.Integer, db.ForeignKey('tag.id'))
```

**修改 Knowledge 模型**：
```python
class Knowledge(db.Model):
    # 移除原有的 category 字段（用标签替代）
    tags = db.relationship('Tag', secondary='knowledge_tag', backref='knowledges')
```

**新增 API**：
- `GET /api/knowledge/tags` - 获取所有标签
- `POST /api/knowledge/tags` - 创建标签
- `PUT /api/knowledge/tags/:id` - 更新标签
- `DELETE /api/knowledge/tags/:id` - 删除标签

**修改接口**：
- `POST/PUT /api/knowledge/items` - 支持传入 tag_ids

## 三、知识关联推荐

### 前端需求

**知识详情页**：
- 展示"相关知识"板块
- 根据相同标签推荐 3-5 篇相关知识

### 后端需求

**新增推荐接口**：
```
GET /api/knowledge/:id/related
Query参数：
  - limit: 返回数量（默认5）
Response:
{
  "code": 200,
  "data": [
    {"id": 1, "title": "...", "tags": [...]},
    ...
  ]
}
```

**推荐逻辑**：
- 基于标签相似度（共同标签数量越多，优先级越高）
- 排除自身
- 按相关性排序
